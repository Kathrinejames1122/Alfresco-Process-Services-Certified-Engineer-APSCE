
# Alfresco Process Services Certified Engineer Certification Exam Guide

[![Hyland Certification](https://img.shields.io/badge/Hyland-Alfresco%20Process%20Services-005A9C?style=for-the-badge)](https://university.hyland.com/pages/cert-apse)

A dedicated, comprehensive study guide and technical reference repository for candidates preparing for the **Alfresco Process Services Certified Engineer (APSCE) Certification Exam**.

---

## Exam Overview

The Alfresco Process Services Certified Engineer certification validates the technical knowledge and skills required to engineer Alfresco Process Services solutions, including architecture, security, APIs, customization, and process logic.

  * Exam Format: Certification assessment; the public certification page does not specify the question format or delivery method.
  * Target Audience: System Administrators for Alfresco Process Services solutions and developers working with APS.
  * Prerequisites: Completion of the APSE certification preparation course is recommended by Hyland; a mandatory prerequisite is not stated.

---

## Core Exam Domains & Knowledge Areas

The following seven topic areas are listed on the official Hyland certification page.

### 1. System Architecture

  * Alfresco Process Services architecture and core components.
  * Embedding and integrating Process Services into applications.
  * Maven modules and custom web resources.

### 2. System Security

  * Security configuration and authentication concepts.
  * Custom identity synchronization.
  * Security configuration overrides.

### 3. APIs

  * Alfresco Process Services Java API.
  * Process Services REST API and service integration.
  * Using APIs to interact with process applications and engine capabilities.

### 4. User Interface

  * Task form customization and form extensions.
  * Form stencils and custom form fields.
  * Extending the Process Services user experience.

### 5. Process Engine

  * Process engine configuration and event handlers.
  * Transaction management and engine behavior.
  * Custom engine extensions and integration points.

### 6. Customization

  * Custom REST endpoints and rule expression functions.
  * Custom data models and reporting.
  * Extending platform functionality for application requirements.

### 7. Process Logic

  * Process modeling, script tasks, and service tasks.
  * Java delegates, Spring beans, and task listeners.
  * Messages, signals, and document templates.
